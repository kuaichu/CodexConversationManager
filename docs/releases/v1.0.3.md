# Codex Conversation Manager v1.0.3 社区增强版

本版本基于 [HikiTanis/codex-conversation-manager](https://github.com/HikiTanis/codex-conversation-manager) v1.0.3 开发。感谢原作者 HikiTanis 提供完整的对话管理、备份、迁移和恢复基础。本仓库在保留上游功能的基础上，增加了批量清理、删除前预览、归档扫描、Ghost 任务修复、模型显示和主题界面。

## 新增功能

- **跨项目批量清理：** 可同时勾选多个项目，一次处理其主对话和关联子代理。每个项目目录可选择保留、移入 Windows 回收站或永久删除，也可一键设置所有项目的目录处理方式。
- **跨项目批量删除对话：** “仅对话”模式支持跨项目逐条勾选主对话并一次删除，关联子代理会一并处理。只有项目下全部相关主对话都被选中且路径通过安全检查时，才允许同时处理项目目录。
- **删除前对话预览：** 对话卡片和批量清理窗口都可打开只读预览，显示标题、Thread ID、工作目录、会话文件路径、角色、时间和真实消息正文。
- **归档会话扫描：** 显式扫描 Codex `archived_sessions`，支持只显示包含归档会话的项目，并标出归档主对话和子代理数量。
- **DesktopOnly Ghost 修复：** 可检测“侧边栏仍存在，但核心索引和 rollout 都不存在”的打不开任务，并清理桌面 catalog、全局状态和任务缓存引用。扫描失败时停止判定，避免误删真实会话。
- **模型显示：** 从 Codex `threads.model` 索引或 rollout 事件的 `payload.model` 读取实际模型名称并显示在对话卡片上；旧会话无法识别时显示“未知模型”。
- **界面升级：** 重新设计主窗口和弹窗，加入可持久化的浅色/深色主题，并改善长对话、子代理和不同窗口尺寸下的布局。

## 安全与兼容性

- 批量删除继续使用原有的 Codex 删除接口、路径校验、索引清理、软件回收站和数据库备份机制。
- 永久删除多个项目目录只要求输入一次“永久删除”，但仍逐项目执行路径和共享目录风险检查。
- 读取、预览、备份和导入不要求 Codex CLI；删除对话和修复侧边栏残留需要 Codex CLI 0.148.0 或更高版本。
- 兼容现有 `.codexchat`、`.codexproject`、`.codexpack` 和 `.codexbundle` 文件。
- 支持 64 位 Windows 10/11，需要 .NET Framework 4.8。程序未进行 Authenticode 签名。

## 下载与校验

同时下载：

- `CodexConversationManager-Windows-v1.0.3.zip`
- `SHA256SUMS.txt`

```powershell
$zip = '.\CodexConversationManager-Windows-v1.0.3.zip'
$expected = ((Get-Content .\SHA256SUMS.txt -Raw).Trim() -split '\s+')[0]
$actual = (Get-FileHash -LiteralPath $zip -Algorithm SHA256).Hash
if ($actual -ne $expected) { throw 'SHA-256 mismatch. Do not run this package.' }
$actual
```

解压到新文件夹后运行 `Start.cmd`。正式删除、恢复或修复前请完全退出 Codex。
